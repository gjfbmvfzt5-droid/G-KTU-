# G-KTU- Ramak Kala Uygulaması

Evet, **masaüstünde klasör oluşturmak en doğru yöntem**. Bu sürüm klasörü otomatik oluşturur:
- `~/Desktop/RamakKala/`
- `~/Desktop/RamakKala/fotograflar/`

## Özellikler
- Ramak kala kaydı + makine bazlı risk puanı
- Fotoğraf ekleme ve hızlı analiz özeti
- Seçilen fotoğrafı masaüstündeki klasöre kopyalama
- CSV kayıtlarını masaüstündeki klasörde tutma

## Çalıştırma
```bash
python3 app.py
```

## Çıktılar
- Kayıt dosyası: `~/Desktop/RamakKala/ramak_kala_kayitlari.csv`
- Fotoğraflar: `~/Desktop/RamakKala/fotograflar/`
